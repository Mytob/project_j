# Jellyfin Proxy v1.5 — Development candidate changelog

v1.5 is planned as a consolidation and quality release, not a feature release.

## Implemented in the working tree

- Verified the local `dev` checkout against GitHub at `8562b23f0da21fe9f6c17f8367a30171b72b635b`.
- Completed repository/source, deployment, security, dependency, test and dashboard discovery; created the v1.5 audit, security, performance, redesign, implementation-plan and test-report documents.
- Corrected `/proc/stat` guest accounting and request-weighted historical HTTP error aggregation.
- Shared component-health sampling across concurrent API/SSE callers, invalidated samples after relevant changes, avoided unchanged health-state writes, removed duplicate SPA bootstrap polling, and added CPU-pressure hysteresis.
- Changed one-time WireGuard configuration retrieval from state-changing GET to authenticated, CSRF-protected POST with no-store headers in both React and fallback UI.
- Added admin container read-only root filesystem, all-capability drop, `no-new-privileges`, and bounded `/tmp` in production and integration Compose.
- Reorganized the six-page admin UI around concise Overview, proxy-only Statistics, host/path Health, compact status details and reduced duplicated security content while retaining current routes and capabilities.

- The WireGuard download/session follow-up avoids an immediate admin bootstrap request after download, preserves the consumed state across SPA navigation, and keeps the loaded admin UI usable after transient status-refresh errors. Browser regression coverage passed using a mocked download response.
- Clarified that the Statistics percentage is the latest error rate and labeled the HTTP error count as cumulative; added a browser regression assertion.
- Stabilized the dynamic security-history screenshot fixture, reviewed the resulting Chromium images, and passed the ordinary three-browser comparison in the release gate.
- Passed `pwsh -NoProfile -File .\build.ps1 test`, `pwsh -NoProfile -File .\build.ps1 release -Version 1.5.0-dev`, and the 2026-10-19 follow-up `pwsh -NoProfile -File .\build.ps1 release -Version 1.5.1-dev`. The full release gate passed for both builds.
- Final staticcheck follow-up fixed the deprecated tar aliases, unused helper, and simplifiable loop; the remaining 32 `ST1005` capitalization warnings are outside the authorized v1.5 scope. Strict same-origin style CSP passed browser checks.
- Deployed `1.5.0-dev` to the authorized Ubuntu 26.04.1 test VPS on 2026-10-18, then updated it to `1.5.1-dev` on 2026-10-19. On the latest deployment all six containers were healthy with zero restarts, public HTTPS routes returned 200/200/403 with valid TLS, both Fail2ban jails were active, and the SSH nftables chain had exactly one IPv4 and one IPv6 rule.
